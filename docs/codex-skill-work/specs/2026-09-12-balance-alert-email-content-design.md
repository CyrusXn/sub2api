# 余额中心告警邮件文案调整设计

## 目标

将余额中心的倍率变化与低余额告警邮件改为简洁中文文案，邮件中的站点、账号、倍率、余额和阈值全部使用本次真实探测数据，不使用固定示例值。

## 范围

- 仅调整余额中心 `multiplier_changed` 与 `low_balance` 两类邮件的主题和正文。
- 保留现有告警触发、去重、持久化队列、收件人和状态推进逻辑。
- 不新增数据库字段、迁移、配置项或邮件模板管理入口。

## 数据来源

- 站点名：沿用探测快照的 `SiteName`，例如 `派大星`。
- 账号名：从真实 `Account.Name` 传入快照；移除开头的 `【站点名】` 前缀后作为邮件账号标签，例如 `【派大星】heavy` 显示为 `heavy`。清理后为空时回退到账号 ID。
- 倍率旧值与新值：使用倍率变化决策中的 `OldValue` 与 `NewValue`。
- 低余额阈值：使用本次告警决策中的 `Threshold`。
- 当前余额：使用本次探测的 `ConvertedBalance`。

## 邮件文案

### 倍率上涨

- 主题：`{站点名}-{账号名}账号-倍率上涨`
- 正文：`{站点名} {账号名}账号倍率上涨，{旧倍率}->{新倍率}`

示例：

- 主题：`派大星-heavy账号-倍率上涨`
- 正文：`派大星 heavy账号倍率上涨，0.01->0.02`

### 倍率下降

- 主题：`{站点名}-{账号名}账号-倍率下降`
- 正文：`{站点名} {账号名}账号倍率下降，{旧倍率}->{新倍率}`

倍率上涨和下降均发送邮件；方向通过比较真实新旧倍率得出。

### 低余额

- 主题：`{站点名}-余额低于{阈值}元`
- 正文：`{站点名}余额：{当前折算余额}元`

示例：

- 主题：`派大星-余额低于5元`
- 正文：`派大星余额：3.25元`

## 格式与安全

- 数值沿用 Go 的紧凑十进制格式，不增加无意义尾零。
- 正文继续输出 HTML，但只包含上述简洁文本。
- 所有动态文本继续进行 HTML 转义，避免账号名或站点名破坏邮件内容。

## 测试

- 先新增失败测试，覆盖派大星 `heavy` 账号倍率从 `0.01` 上涨至 `0.02`。
- 覆盖倍率下降时主题和正文使用“倍率下降”。
- 覆盖低余额主题取真实阈值、正文取真实折算余额。
- 覆盖带 `【站点】` 前缀的真实账号名提取，以及空账号名回退账号 ID。
- 运行余额中心相关 Go 测试、`gofmt` 和 `git diff --check`。
